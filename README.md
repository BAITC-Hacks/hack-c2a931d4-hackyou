# TraceGraph — анализ сети денежных переводов

Проект команды **hackyou** для кейса HackAlem «Граф денег». TraceGraph помогает аналитику понять, кто собирает, распределяет и переводит средства, и выбрать участников для дальнейшей проверки. Результат — направленный граф переводов, гипотезы ролей, сообщества и приоритеты с объяснениями.

## Что реализовано

- Кейсы, загрузка и проверка трёх Parquet-файлов, запуск анализа и история результатов.
- Диаграммы ролей и приоритетов, поиск участников по GID, фильтры и карточки с основаниями выводов.
- Граф входящих и исходящих переводов: направления, суммы, число операций и переходы между участниками.
- Три CSV для сдачи и отдельный Excel-файл с русским текстом и точными идентификаторами. JSON сохраняются как внутренний снимок для API, графа и карточек.
- В Python SDK — подробные операции, пошаговые расследования и три локальных аналитических агента. Эти функции SDK пока не подключены к веб-интерфейсу.

## Установка и запуск

Нужны **Python 3.12**, **Node.js 22.12+ или 24 LTS** и **Git**. Интернет требуется для установки зависимостей. Docker, API-ключи и отдельный сервер БД не нужны.

Скачайте проект:

```sh
git clone https://github.com/BAITC-Hacks/hack-c2a931d4-hackyou.git
cd hack-c2a931d4-hackyou
```

**Windows PowerShell** — выполните из корня проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
py -3.12 -m venv .venv-engine
.\.venv-engine\Scripts\python.exe -m pip install -r ml\requirements-lock.txt
.\.venv-engine\Scripts\python.exe -m pip install -e ./ml --no-deps
npm.cmd --prefix frontend ci
.\.venv\Scripts\python.exe scripts\dev.py
```

Если `py` недоступна, замените `py -3.12` на `python` версии 3.12. Активация окружений и создание `.env` не требуются.

Откройте **[http://127.0.0.1:5173](http://127.0.0.1:5173)**. Скрипт запускает интерфейс и API вместе; `Ctrl+C` останавливает оба. Повторный запуск — только последняя команда для вашей ОС.

## Как проверить решение

1. В интерфейсе нажмите **«Новый кейс»** и создайте кейс с любым названием.
2. Загрузите три файла из папки `data/` репозитория: **`nodes.parquet`**, **`edges.parquet`**, **`transactions.parquet`**. Нажмите **«Проверить и сохранить»**. Ожидается: **2 248 участников, 3 119 связей и 4 840 операций**.
3. Нажмите **«Запустить анализ»** и дождитесь статуса **«Готово»**. В обзоре выберите роль или приоритет, найдите участника по GID и откройте его карточку.
4. Нажмите **«Исследовать связи»**. Отправители расположены слева, получатели — справа. Переключите входящие/исходящие связи; нажмите сумму для деталей или соседний узел для перехода.
5. В **«Обзор и участники» → «Результаты анализа · CSV»** скачайте три файла: `nodes_roles.csv`, `clusters.csv`, `top_nodes.csv`. Для просмотра в таблицах есть отдельная кнопка **«Скачать для Excel · .xlsx»**. Обновите страницу: кейс и результат должны сохраниться.

Для короткой проверки на полностью вымышленных данных используйте три Parquet из [`synthetic-demo/`](synthetic-demo/): ожидаются **38 участников, 37 связей и 96 операций**. Подробная сверка с требованиями — в [аудите готовности](docs/submission-readiness.md).

## Технологии и архитектура

```text
React / TypeScript → FastAPI → отдельный процесс TraceGraph AI
                        ↓                  ↓
                 SQLite + файлы      граф и ML на CPU
```

| Компонент | Технологии |
| --- | --- |
| Интерфейс | React, TypeScript, Vite, TanStack Query, React Router |
| API и хранение | FastAPI, Pydantic, SQLAlchemy, Alembic, SQLite |
| Анализ данных | pandas, NumPy, PyArrow, NetworkX, SciPy |
| ML | PyTorch Autoencoder; резервная модель — scikit-learn IsolationForest |
| Экспорт | CSV, JSON, XLSX / openpyxl |

Backend и движок используют отдельные Python-окружения. Расчёты выполняет движок; API проверяет и сохраняет результаты, интерфейс показывает их аналитику.

## Данные, внешние сервисы и ограничения

- В `data/` находится обезличенная выборка организаторов HackAlem: узлы, связи и операции за июль 2026 года.
- После установки решение работает локально, без LLM и внешних API. Демонстрация доступна по локальному адресу выше.
- Роли и приоритеты — гипотезы для проверки, а не доказательство нарушения. Разметки подтверждённых ролей в данных нет.
- Данные ограничены одним банком, исходящим обходом до четырёх шагов, порогом 5 000 ₸ и точностью дат до дня. Связи не доказывают движение одних и тех же денег.
- На графе показываются до 6, 12 или 20 соседей по выбранному лимиту; итоги участника учитывают всё окружение.
- Это локальный MVP без авторизации и разграничения доступа, рассчитанный на один процесс API.
