## Адресные проверки

```powershell
.\.venv\Scripts\python.exe -m pytest ml/tests -q
.\.venv\Scripts\python.exe -m ruff check --select E9,F ml/src ml/examples ml/tests
```

Результат: **8 passed in 12.93s**, статические проверки прошли.

Проверены целостность семи выходов и всех gid, граница depth=4, неполный баланс seed, изоляты, сохранение повторяющихся транзакций, отклонение неверной агрегации, принудительный переход на IF, JSON round-trip расследования, отклонение изменённой истории, пределы 3/5, изоляция данных getters, малый граф из одного узла и сброс состояния после неуспешного анализа. Уверенность не растёт от повторного просмотра evidence.

Дополнительно при реализации проверены воспроизводимость AE/IF, сохранение RNG/числа потоков вызывающего процесса и обучение preprocessing только на train-части. Эти адресные проверки не являются бенчмарком качества выявления нарушений: размеченных ролей и подтверждённых исходов в датасете нет.

## Границы результата

Система выдаёт гипотезы для проверки. Расследование в текущем прототипе последовательно раскрывает рассчитанные свидетельства и рекомендует недостающие данные; внешние источники оно не получает и новую уверенность из повторного чтения не создаёт. Истинность роли не измерена через accuracy. Веб-интерфейс, HTTP-адаптер и постоянное хранение сессий реализует инженер платформы по контракту SDK.
